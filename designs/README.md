# Selected designs

`selected_designs.csv` lists the **six experimental mutants** plus wild-type p35.
Designed amino-acid sequences are not included.

- Five helix designs: RFdiffusion + ProteinMPNN + AlphaFold 3
- Construct **6**: ProteinMPNN only on the wild-type p35 loop (`0_3_sample358`)
- `experimental_label` follows the original working-folder prefixes
  (`1_`, `5_`, `11_`, `noRK1_`, `noRK2_`, loop `6_`)
- `no_R_or_K=true` means the designed helix or 147–160 loop contains neither
  arginine nor lysine
